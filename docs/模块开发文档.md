# 模块开发文档

## 1 工程结构

```text
assets/
  scenes/Main.scene               可直接运行的 Cocos 主场景
  resources/levels/               可序列化关卡清单和关卡 JSON
  scripts/
    GameView.ts                   Cocos 表现层、触摸、动画和 HUD
    app/GameManager.ts            对局入口、胜利结算和星级计算
    managers/LevelManager.ts      关卡加载、解锁和进度查询
    core/                         无 Cocos 依赖的玩法核心
      types.ts                    数据模型
      math.ts                     方向、距离和向量
      geometry.ts                 折线几何、精确点击和动画裁切
      collision.ts                AABB 射线检测
      arrows.ts                   ArrowBase 与三种箭头
      game-core.ts                生命、提示、胜负和状态
      level-validation.ts         关卡结构和碰撞盒校验
    storage/                      Cocos/微信本地存储与存档模型
    utils/JsonResourceLoader.ts   Resources JSON 加载
settings/                         Cocos 3.8.6 工程设置
build-templates/                  Web 构建页面模板
tests/                            核心算法、关卡与进度测试
```

## 2 运行链路

1. `Main.scene` 中的 `GameView` 启动。
2. `GameView` 请求 `GameManager.create()`。
3. `GameManager` 创建平台存储，并由 `LevelManager` 加载关卡清单。
4. `LevelManager` 通过 `resources.load` 读取 JSON，调用 `validateLevel` 后创建 `GameCore`。
5. 点击时，`GameView` 用 `hitTestArrow` 找到目标，再由 `GameManager.checkMove()` 调用射线检测。
6. 畅通时播放折线“拉绳”飞出动画，结束后调用 `commitClear`。
7. 受阻时播放短距离前进和退回动画，结束后调用 `registerBlocked`。
8. 通关时 `GameManager` 计算星级，`LevelManager` 保存最高星级并解锁下一关。

核心判定与表现动画之间只通过只读结果和完成回调交互，模型不会在动画过程中提前改变。

## 3 核心算法

### 3.1 射线阻挡

`castRay` 从箭头尖端沿实际移动方向检查墙体和其他箭头。墙体使用轴对齐矩形，箭头使用包围盒或逐段扩展 AABB；取到棋盘边界前最近的正向交点作为阻挡物。

反转箭头的射线方向来自 `moveDirection`，与外观 `dir` 相反。

### 3.2 线条自身阻挡

长折线箭头参与自碰撞检测，但跳过与尖端相连的最后一段，避免起点处自撞。折返返回出口方向的线条会被判为自堵。

### 3.3 点击命中

短箭头把点击点逆旋转到局部坐标，再检测箭杆宽度和箭头三角形；长折线逐段计算点到线段距离。以此替代简单矩形命中，避免遮挡处误点。

### 3.4 飞出与退回

长折线飞出不是整体平移，而是尖端向前、尾端沿原路径回缩。`slicePolyline` 从虚拟延长折线中裁出固定长度线段，形成“拉绳子”效果。

受阻退回只改变绘制偏移，模型中的折线坐标不变化。

## 4 关卡格式

关卡清单：

```json
{
  "version": 1,
  "levels": [
    {
      "levelId": "iter3-demo-01",
      "order": 1,
      "name": "第一关 · 先看出口",
      "resource": "levels/level-001"
    }
  ]
}
```

支持两种箭头：

- 短箭头使用 `x`、`y`、`dir`、`bend` 生成外观和碰撞盒。
- 长折线使用 `points` 保存从尾到头的正交折线。

共同字段包括 `id`、`type`、`layer`。`type` 可取 `normal`、`fixed`、`reverse`。

墙体使用 `x`、`y`、`width`、`height` 描述轴对齐区域。所有坐标与棋盘共享同一套左上角原点、`y` 向下的逻辑坐标。

## 5 进度与星级

存档键为 `arrow-game-save`。存档包含：

- `schemaVersion` 和 `updatedAt`。
- `maxUnlockedOrder`。
- 每个关卡的状态、历史最高星级和完成时间。
- 音乐、音效和振动设置。

星级规则：

- 满生命通关为三星。
- 损失生命但仍有剩余生命为二星。
- 其他完成情况至少为一星。

历史星级只升不降。通关后保存当前关卡成绩，并把下一顺序关卡标记为已解锁。

## 6 扩展方式

新增箭头类型时继承 `ArrowBase`，实现 `movable` 和必要时的 `moveDirection`，并在 `createArrow` 注册。新增关卡时复制一份 JSON，更新 `id`、尺寸和箭头数据，再加入清单。

不要在 `core` 中导入 Cocos 节点、`GameView` 或平台存储。表现层不要自行判断路径是否受阻，所有规则必须经过 `GameCore.checkMove`。
