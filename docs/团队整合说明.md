# 团队代码整合说明

## 1 整合前状态

主分支包含分层管理器、JSON 关卡清单、关卡解锁、星级存档和项目文档，但缺少可直接运行的 Cocos 场景。

成员曾祥楠的迭代三工程包含完整 Cocos 场景、17 项核心算法测试、长折线几何、精确点击命中、自碰撞检测和“拉绳式”飞出动画，但尚未接入星级和关卡解锁。

## 2 采用方案

以成员的 Cocos 场景和高精度射线算法作为玩法基础，整合主分支的应用管理能力：

- `GameView` 负责表现、输入和动画。
- `GameManager` 负责对局入口、星级计算和通关结算。
- `LevelManager` 负责 JSON 清单、资源加载、解锁和关卡创建。
- `StorageManager` 负责微信/Cocos 本地存档和历史最高星级。
- `GameCore` 继续作为无引擎依赖的纯逻辑核心。

旧版网格核心已由成员的长折线核心替代。旧代码仍保留在 Git 历史中，不参与当前工程编译。

## 3 关卡

当前正式关卡为：

- `iter3-demo-01`：短箭头回归关，覆盖普通、固定、反转箭头和墙体。
- `long-maze-01`：24 条长折线迷宫，覆盖线条互阻、自身折返和长线动画。

两关均通过 JSON 加载，不再在表现代码中写死。

## 4 验收

- 核心算法由整合测试和成员原有测试覆盖。
- 关卡格式通过命令行校验。
- TypeScript 通过静态检查。
- 场景保留原有 Cocos UUID 和 `.meta`，可继续用 Cocos Creator 3.8.6 打开。

原始成员目录 `other member/zxn_迭代三` 保留在本地作为交付参考，当前工程只纳入运行所需代码、场景和配置。
