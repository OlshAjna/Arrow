# 部署说明

## 1 环境

- Cocos Creator 3.8.6
- Node.js 24 推荐版本，用于命令行校验
- 微信开发者工具，仅在构建微信小游戏时需要

## 2 打开与预览

1. 在 Cocos Dashboard 中导入项目根目录。
2. 使用 Cocos Creator 3.8.6 打开。
3. 等待资源导入完成。
4. 打开 `assets/scenes/Main.scene`。
5. 点击预览。

主场景已经把 `GameView` 挂在 Canvas 上，棋盘、HUD、触摸监听、提示、重置和结算界面均由代码创建，不需要手工搭节点。

## 3 命令行校验

```powershell
pnpm install
pnpm typecheck
pnpm validate:levels
pnpm test:domain
git diff --check
```

`test:domain` 覆盖短箭头关、长折线关、固定/反转箭头、阻挡、胜利、星级保存和下一关解锁。

## 4 Cocos Web 构建

在 Cocos Creator 的“构建发布”面板选择 Web Desktop，使用 `assets/scenes/Main.scene` 作为启动场景并构建。`build-templates/web-desktop` 已提供全屏白底页面模板。

## 5 微信小游戏构建

1. 在项目设置中填写微信小游戏 AppID。
2. 在“构建发布”选择微信小游戏。
3. 设置输出目录并执行构建。
4. 用微信开发者工具导入构建目录。
5. 检查真机触摸、画面比例和本地存档。

`CocosLocalStorage` 在微信环境优先使用 `wx.getStorageSync` 和 `wx.setStorageSync`，其他环境回退到 Cocos `sys.localStorage`。

## 6 常见问题

**打开场景后没有画面**

确认使用的是 Cocos Creator 3.8.6，且 `GameView.ts.meta` 与 `Main.scene` 一起保留。场景通过脚本 UUID 绑定组件，不要单独复制 `.ts` 文件而遗漏 `.meta`。

**资源加载失败**

确认 `assets/resources/levels/level-manifest.json` 存在，清单里的 `resource` 不含 `.json` 后缀。

**下一关仍被锁定**

清除本地键 `arrow-game-save` 后重新开始；或检查当前关是否完成、存档中的 `maxUnlockedOrder` 是否更新。

**短箭头或长折线显示异常**

执行 `pnpm validate:levels`，并检查箭头 `points` 是否从尾到头、坐标是否超出棋盘。

## 7 发布检查

- 主场景可预览并完成两关。
- 普通、固定、反转箭头表现正确。
- 提示、重置、生命、胜利和失败可用。
- 通关后星级保存，下一关解锁。
- `pnpm typecheck`、`validate:levels`、`test:domain` 全部通过。
- 不提交 `build`、`library`、`temp`、`local`。
